# 疏花草甸原始参考

以下均为经用户选定方向的 ImageGen 概念图，不是实物扫描与实拍。同角度对照用各单体资产目录下的模型渲染。体积、不能从概念图确认的背面，以及物理大小根据植物与昆虫形态独立重建。

- [场景方向](scene-concept.png)：矮草占多数、近处小花、路边稀疏草丛、右侧宽冠树与侧光。构图参考，不作为运行时背景。
- [草型](grass-forms-concept.png)：首批使用左侧狗牙根与中间狗尾草；右侧芒草不在首批。
- [草地小花与羊茅](low-plants-concept.png)：上排由左至右为细叶羊茅、白车轴草、雏菊；下排阿拉伯婆婆纳、夏枯草、虞美人。各自为近看图，不代表相对大小。
- [宽冠栎树](oak-concept.png)：树冠层次、主枝和叶片局部。
- [柑橘凤蝶](swallowtail-concept.png)：展开的背视、半收翅的侧前视；两张用于核对主要翅纹和翼根，不能作为背腹花纹完全等同的证据。
