# 鱼种制作与接入

以下仓库路径均以 RealWorldBuilder 根目录为准。现成的鱼种在 `fish/arowana/`，可以打开其 Blender 工程，也可以读代码检查加载和播放方式。

## 概念图与游戏资产

- 侧视图优先采用平视、近正交构图，整条鱼入画，嘴、尾柄和鱼鳍边缘清楚。结构难以从侧面确定时，补俯视或斜视。按需要放入干净底色或真透明背景，生成后检查 Alpha。展示图可以另行布光。
- 一个参考用于定一个问题。实拍或标本用来对体型和动作，概念图用来定颜色和材质观感。龙鱼体型迭代就是先按吻端到尾鳍根部量体长，再量背腹最深处，接着加深躯干并调整鳍根。记录项目采用的口径和依据，便于以后量同一个部位。
- 使用可用的 ImageGen 能力。可调用 `imagegen` Skill 时按它的工作方式生成或编辑。用户指定图像模型时以工具可核实的模型为准。记录参考文件或链接、实际工具、提示词和采用的输出路径。
- 将侧视参考作为建模和 UV 对位的依据。底色尽量留出灯光可调的空间，把高光、鳞片起伏和透光分别交给材质通道。在 Blender 中将底色按 sRGB 处理，法线、粗糙度和金属度图使用 Non-Color。半透明鳍在亮底和暗底都看一遍，留意白边、黑边、排序与薄膜质感。
- 需要背景时，围绕鱼的活动区留出清楚的轮廓和空间。先在目标画幅里看背景和鱼的遮挡关系，再确定水波、阴影、气泡或其他场景效果。

## Blender 与 GLB

- 优先用可用的官方 Blender MCP 操作工作副本。批处理、核查或稳定导出可用 Blender Python 与 CLI。并行任务使用各自的文件路径和 Blender 会话，脚本及参考图按当前工作树找文件。
- 先检查实体体型和鳍根，再做鳞片与反光。参考龙鱼的坐标约定，鱼头朝 +X，Blender 中 +Z 向上，导出的 glTF 中 +Y 向上。新鱼的长度和在缸里使用的比例要在设计中记下来。导出后核对朝向和尺寸。
- 使用该鱼种自己的骨骼命名和权重。调整躯干轮廓时一起检查鳍根、相应骨骼枢轴和蒙皮。用缓游、急转、最弯曲处检查接缝，尤其留意胸鳍和尾柄。
- Blender 源文件应能凭打包或相对路径贴图重开。导出时选择鱼本身的网格与骨骼，导出任务需要的动画、UV、法线和切线。用项目的 Three.js 加载实际 GLB，检查纹理、材质、骨骼和绑定姿势，GLB 自带动画时再对照它与实时姿态。带根节点位移的烘焙动画要核对一次根变换，避免浏览器里的鱼整体偏移。

## 独立预览与水族箱

- 每个鱼种用自己的 `fish/<species>/`。当前约定可看 `fish/arowana/index.js`，鱼种入口包含 `id`、相对仓库根目录的 `modelFile` 与 `createSwimmer(object, route)`。控制器的 `update(timeSeconds)` 按绝对播放时刻求姿态，并提供 `duration` 供循环和进度条使用。主场景用 `getMotion()?.center` 时由控制器返回它。
- `fish/load-fish.js` 解码 GLB，再为每条鱼复制独立的蒙皮骨骼。几何、材质和纹理可共享，改个体材质前先复制该材质。两条同种鱼一起验收时，推进其中一条的时间并检查另一条的姿态。
- 独立预览参考 `fish/arowana/preview.js` 和 `src/fish-preview.js`，可用更合适的相机距离和独立路线查看动作。主缸的示例路线在 `src/cruise-route.js`，可复用 `fish/swim-route.js`。多鱼在同一水域时，由场景安排路径、深度、间距和启动相位。需要响应用户输入时，在场景层接收输入，在鱼种层处理动作的进入、过渡和恢复。
- 目前 `build.mjs` 明确列出龙鱼的两套构建入口，`src/embedded-data.js` 从每页读入一个模型。新增预览时在任务分支添加对应入口。首次同缸组合不同鱼种时，再扩展嵌入和加载逻辑，按鱼种 ID 读取各自的 GLB，由 `src/viewer.js` 创建入缸的个体。集成时先合并源码和资源引用，再重新生成 HTML。

## 预览验收

| 检查位置 | 要看到的结果 |
| --- | --- |
| 独立预览 | 鱼能自动开游。暂停后画面稳定，拖动能到指定时刻。两端转弯和循环接缝连贯，极限姿态下鱼鳍与躯干衔接且在画幅内。 |
| 水族箱 | 同一份模型在目标位置、尺寸、背景与灯光下能正常游动。涉及多鱼时检查前后遮挡、路径交叉和各自的动作。涉及交互时，用实际输入触发，观察动作过渡和恢复，并检查快速重复触发。 |
| 透明播放或嵌入 | 本轮涉及 `aquarium.html#overlay` 时，在外部画面上确认 Alpha 和半透明轮廓，检查播放控件是否按该入口预期显示。 |
| 构建与回归 | 执行 `npm run build`，打开生成的页面。按本轮范围检查离线加载、浏览器错误、现有鱼种以及相应的背景或灯光操作。对比图按同一相机、灯光和时刻取帧。 |
