# 创作任务与交接

并行设计或跨会话交接时，可以把这份模板放在资产目录，或用作会话的第一条消息。填与本轮有关的项。

## 开工

- **鱼种、物件或场景资产** — 名字、目录、分支与起始提交
- **本轮范围** — 讨论、概念、材质、模型、独立预览或进缸
- **目标画面** — 观赏距离、要还原的形态与材质、需要的动作或交互
- **参考与已定方向** — 原照、实拍视图、选定的生成参考与关键特征。单图还原时记录尺寸依据和推定的侧背结构
- **验收画面** — 例如回到原照机位比较轮廓，旋转近看毛向，或在掉头时检查鳍根
- **接入范围** — 共用代码的预计改动，以及与其他鱼种的交接点

## 交接

- **采用的版本** — 分支或提交，选定参考图、贴图、Blender 工程、GLB 与预览路径
- **素材记录** — 参考来源、生成工具、提示词、采用或修改的文件
- **接入信息** — 鱼种 ID、朝向与比例、动作控制入口、所需场景改动
- **验收结果** — 实际打开的入口、观察的角度或交互、对照图或录屏，以及仍待确认的细节

示例开工指令

> 用 `$aquarium-creation` 设计一条半月斗鱼，先做到侧视概念图。放在 `fish/halfmoon-betta/`，以尾鳍展开、鳍膜透亮和实际鱼体比例作为选图标准。
