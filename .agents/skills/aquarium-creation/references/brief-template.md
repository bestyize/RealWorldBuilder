# 创作任务与交接

每条并行任务可以把这份模板复制到自己的鱼种目录，或直接用作会话的第一条消息。填与本轮有关的项。

## 开工

- **鱼种或场景资产** — 名字、目录、分支与起始提交
- **本轮范围** — 讨论、概念、材质、模型、独立预览或进缸
- **目标画面** — 观赏距离、体型与材质、能代表这条鱼的动作或交互
- **参考与已定方向** — 实物参考、已选概念图、需要沿用的特征
- **验收画面** — 例如正侧看条纹和透明鳍，掉头看鳍根，完整循环中鱼始终入画
- **接入范围** — 共用代码的预计改动，以及与其他鱼种的交接点

## 交接

- **采用的版本** — 分支或提交，选定概念图、贴图、Blender 工程、GLB 与预览路径
- **素材记录** — 参考来源、生成工具、提示词、采用或修改的文件
- **接入信息** — 鱼种 ID、朝向与比例、动作控制入口、所需场景改动
- **验收结果** — 实际打开的入口、观察的姿态或交互、截图或短录屏、待检查项

示例开工指令

> 用 `$aquarium-creation` 设计一条半月斗鱼，先做到侧视概念图。放在 `fish/halfmoon-betta/`，以尾鳍展开、鳍膜透亮和实际鱼体比例作为选图标准。
