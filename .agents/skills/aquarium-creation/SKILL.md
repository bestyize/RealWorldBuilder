# RealWorldBuilder 创作与接入

按用户选定的阶段和交付范围推进。讨论、概念图、建模、独立预览和进缸都可以是本轮的终点。用户提供的图或已选定的方向可以直接作为输入。迭代时保留可回看的基准，用新候选呈现本轮变化。

## 还原模型与项目接入

照片或定稿图的还原可用 Skill [`$photo-to-3d`](../photo-to-3d/SKILL.md)。需要把模型作为本项目资产交付时，读[还原资产的项目接入](references/photo-to-3d.md)了解目录、离线预览和验收方式。

## 水族箱与鱼种创作

### 1. 目标

用一句话定义在屏幕上要看到什么，再写下能在预览里判断的标准。鱼种通常需要明确品种和体型、目标相机距离、代表性动作、所需交互，以及本轮交付到哪个入口。先记录真实参考和用户已定的风格，再根据画面用途补足设计决定。需要在多个会话交接时，用[任务与交接模板](references/brief-template.md)记录这些内容。

### 2. 设计

查真实个体的侧面与游动参考。比较能影响成像的形态，例如鱼体深浅、鳍的起止位置、尾柄宽度和色带分布。以实物参考定结构，以概念图定配色、光感和画面表达。概念阶段优先用 ImageGen 制作可比较的侧视候选，需要时补俯视或四分之三视图。打磨现有候选时沿用选定参考，记录哪些特征需要保留。保存采用的参考、提示词和最终图。

### 3. 实现

先把概念拆成能用于实时渲染的资产，例如底色、粗糙度、法线和需要透明度的鳍膜。用 Blender 建立轮廓、UV、材质和骨骼，再导出带贴图的 GLB。随后用独立预览检查摆尾、鳍动、滑行与掉头，在用户要求进缸时把同一资源接进水族箱。模型和个体姿态跟着鱼种走，游动路线和场景由调用方提供。做素材、模型或实时接入时，读[鱼种制作与接入](references/fish-production.md)。

### 4. 验收

按目标检查相应产物。概念图用同方向与真实参考比轮廓。模型在侧面与转身画面看体型、鳞片反光、鳍根和透明边缘。动画看完整一圈及循环接缝，确认摆尾、转向、暂停和拖动进度符合预期。进缸时还要在实际水族箱里看比例、画幅、遮挡和本轮涉及的交互。比较新旧时用同一相机、灯光和动作时刻。通过实际打开生成的页面验证离线播放。未覆盖的平台和交互写进交接记录。

### 5. 交付

给出本轮选定的素材或可编辑源文件、小样预览入口、验收结果和下一位要用的文件。完成鱼种通常交付 Blender 工程、GLB、鱼种的游动代码和独立 `preview.html`，进缸时同时给出 `aquarium.html`。区分当前可打开的本地预览和用户要求发布的线上版本。发布时按约定的分支与版本验证实际可访问的页面，并保留已有 release。

## 并行开工

并行设计时，以鱼种、物件或场景资产为单位，从同一个基线创建独立工作树。把尝试中的渲染和贴图放在本任务的输出位置，用分支或备选文件保留已选定版本。多个任务都要改共享文件时，交接各自的接入点，将共用入口的修改集中集成。提交前从合并后的源码重建网页并检查已有鱼种和本轮受影响的物件预览。图像候选、建模和独立预览可以在各自分支先验收。
