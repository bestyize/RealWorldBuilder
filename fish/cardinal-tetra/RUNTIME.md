# 宝莲灯：独立单鱼 / 松散鱼群预览

构建仅写本鱼种页面，不修改展厅、水族箱、依赖或其他鱼种：

```sh
node fish/cardinal-tetra/build.mjs
node --test fish/cardinal-tetra/swim.test.mjs
```

打开 `preview.html` 可离线播放。默认 10 条，右上按钮切换单鱼。切换时暂停在当前时刻，方便检查，再按播放继续。拖动或方向键旋转，滚轮/加减键缩放，Home/重置视角复位。

## 性能边界

- GLB 解码一次，贴图共享；每个网格 primitive 只复制一份绑定姿态几何。
- 使用 `THREE.InstancedMesh`，最多 10 个实例，不按鱼复制顶点、骨骼或材质。
- 每个实例有不同尺寸、尾摆相位、前后/横向/高度位置。CPU 每帧只更新实例矩阵，尾部弯曲由 GPU 顶点着色器完成。每种原材质复制一次以隔离本页的着色器参数。
- 42 秒闭合路线，可任意跳转。个体有小幅错时前进和横向浮动，不是同步队列。此版本是确定性代表性鱼群，不是碰撞物理/通用 boids 模拟。
- 网格和贴图负载随单鱼资产变化，但实例数固定上限为 10。透明鳍不具备逐实例透明面排序保证，应以实际浏览器的交叉遮挡检查为准。

## 测试边界

Node 测试验证资源共享、实例上限、路径、循环、最小中心间距、切换和着色器注入；不会假装 CPU 顶点已经执行 GPU 变形。真实 GLB 加载及 GPU 编译、尾摆、交叉遮挡、全鱼入画还需要离线浏览器验证。视觉写实程度与这些功能测试分开记录。

## V2 材质更新

背部、红腹、蓝带分别使用不同粗糙度；蓝带通过标准 glTF 薄膜虹彩随光线和视角变化，没有自发光、泛光或运行时染色补丁。材质和贴图仍由十条鱼共享，几何、游动、相位、镜头与灯光保持 V1 不变。新增两张小尺寸共享贴图，不增加实例或绘制分组。Blender 与 glTF 的导出衔接及近看局限见 `MODEL.md`。此版改善釉面感，但没有把原始绘制色彩细节伪称为真实微观鳞片。
