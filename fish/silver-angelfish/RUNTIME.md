# 银神仙鱼独立实时预览

本目标只制作 `Pterophyllum scalare` 单鱼预览，不登记到展厅、不加入水族箱、不改变现有鱼种。

从仓库根目录运行：

```sh
node fish/silver-angelfish/build.mjs
node --test fish/silver-angelfish/swim.test.mjs
```

直接打开 `fish/silver-angelfish/preview.html`。GLB 和脚本已内嵌，可离线打开。拖动/方向键旋转，滚轮或 `+` / `-` 缩放，Home 或「重置视角」复位。支持暂停、任意拖动进度和恢复播放。这个目标不会重建 `aquarium.html`、展厅或其他预览；原 `npm run build` 也不会覆盖本页。

动作按绝对时间计算，以 48 秒闭合路线重复。保持扁高躯干稳定，尾柄及尾鳍只有低幅摆动，背/臀鳍末端有轻微波动，胸鳍和腹鳍细丝辅助悬停。路线包含两段低速悬停和短距离缓游，不套用锦鲤的大幅躯干弯曲。

GLB 保留可编辑的绑定骨架；浏览器把静止绑定姿态网格变换至鱼种坐标后，为每个实例单独复制几何。实时过程不同时叠加骨骼动画。贴图/材质保持共享只读。

功能通过不等于写实验收通过。正式验收需检查真实 GLB 的侧面、正面厚度、后斜面、转弯、长鳍完整入画、鳍根连续性和亮/暗背景透明度。不能仅以测试或构建成功宣称达到实拍效果。

V2 材质近看：生产页面最小观察距离为 7.5，初始全鱼视角仍为桌面 17.5、触屏 20.5。可滚轮、加号或双指张开放大检查鳞片；「重置视角」回到完整鱼体。近看时鳍尖可能超出画面，这是局部材质查看，不改变初始构图。
