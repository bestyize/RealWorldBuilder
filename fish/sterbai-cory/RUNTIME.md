# 斯氏鼠鱼：独立底栖预览

```sh
node fish/sterbai-cory/build.mjs
node --test fish/sterbai-cory/swim.test.mjs
```

只生成本目录 `preview.html`，GLB/脚本内嵌，离线可用；不修改水族箱、展厅、其他鱼或依赖。

36 秒路线包含六次短距离搜索：平滑加速、减速后静止，停留期间轻微低头探查。胸鳍在行进阶段较积极划动，停留时收敛，不使用锦鲤或中层鱼群的持续巡游模式。动作以绝对时刻求解，支持暂停、任意进度和闭环重播。

独立预览不绘制参考平面或贴地阴影，可直接从下方观察。动作仍按变形后的顶点保持原有离地高度，便于以后放回水族箱。没有模拟砂砾、触须碰撞或真实觅食。

拖动/方向键旋转，滚轮/加减键缩放，Home/重置视角复位。全角度观察和触屏横向布局沿用独立预览组件。模型的可编辑骨架保留在源资产；实时实例使用独立几何变形，避免重复叠加蒙皮。

功能验收和写实验收分开。Node 测试覆盖静止区间、循环/任意跳转、独立性、俯仰范围与所有顶点的底面净空。真实模型仍须用实际 WebGL 检查头形、斑点、甲片、须与鳍根，不能以构建通过代替视觉结论。
